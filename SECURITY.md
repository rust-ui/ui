# Security Policy

Do not report security vulnerabilities in a public issue or discussion.

Use [GitHub's private vulnerability reporting](https://github.com/rust-ui/ui/security/advisories/new) instead. This keeps exploit details private while maintainers investigate and prepare a fix.

Supported versions:

- `main`
- The latest published release

Include the affected version or commit, impact, reproduction steps or proof of concept, and any suggested mitigation. Do not include secrets that are still valid.
